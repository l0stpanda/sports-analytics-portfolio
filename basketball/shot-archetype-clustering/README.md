# Shot Archetype Clustering

## Project Proposal

Can NBA players be grouped into an offensive archetype based solely on their shot profile data?

This project aims to explore whether players can be grouped into offensive archetypes based on the NBA's tracking and play-by-play data. The central question is: if we remove player names, positions, and reputation, do players naturally group into categories that resemble how analysts describe them (such as rim-running centers, three-point specialists, shot creators, mid-range scorers, or balanced offensive players)?

This project will be done using unsupervised clustering techniques to identify player groups and compare them to their commonly-accepted player roles. I will use data points such as shot location frequency, efficiency by zone, 3 pt/rim attempt rate, and assisted vs. unassisted field goals.

The project will document the data collection process, feature engineering choices, clustering methodology, evaluation metrics, and limitations, including the subjectivity of choosing the number of clusters and the fact that offensive roles are influenced by team context and coaching systems.
